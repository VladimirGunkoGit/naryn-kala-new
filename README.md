# ROSTER — школа Counter-Strike 2 (лендинг)

Полная копия сайта <https://cs2shablon.tilda.ws/> — одностраничный лендинг школы
CS2 «ROSTER». Сайт собран на Tilda, но вся значимая вёрстка, стили и логика
находятся в одном пользовательском блоке, поэтому его удобно править прямо
руками.

## Как открыть локально

Из-за загрузки ассетов по относительным путям открывать нужно через локальный
сервер (не двойным кликом по файлу):

```bash
python3 -m http.server 8099
# затем открыть http://localhost:8099/index.html
```

## Структура

```
index.html   — вся страница (Tilda-обёртка + пользовательский блок с лендингом)
css/         — стили Tilda (сетка + блоки страницы)
js/          — скрипты Tilda (jquery, ленивая загрузка, статистика и т.д.)
images/      — изображения (маскот hero.png, geo.png, resp.png, faq-avatar.png, favicon)
```

Все ссылки на CDN Tilda заменены на локальные пути — сайт работает офлайн и
не зависит от серверов Tilda.

## Где что редактировать в `index.html`

Основной контент — это **пользовательский блок** между комментариями
`<!-- nominify begin -->` и `<!-- nominify end -->`. Всё остальное — служебная
обёртка Tilda, её трогать почти никогда не нужно.

Внутри блока три части:

1. **`<style>…</style>`** — все стили лендинга. В начале объявлены CSS-переменные
   с цветами (`--orange`, `--cobalt`, `--bone` и т.д.) — меняешь их и меняется
   вся палитра. Дальше идут стили по секциям (topbar, hero, trainings, fit, geo,
   pricing, faq, contacts, форма и т.д.).

2. **HTML-разметка** — секции идут по порядку и помечены комментариями
   (`HERO`, `01 / КАК УСТРОЕНО`, `02 / КОГО ИЩЕМ`, `03 / ОТКУДА ИГРАЕМ`,
   `04 / ДИСЦИПЛИНА`, `06 / СТОИМОСТЬ`, `07 / ПРОБНЫЙ УРОК`, `08 / FAQ`,
   `09 / КОНТАКТЫ`, `10 / ЗАЯВКА`). У каждой секции есть `id`, по которому на неё
   ведут якорные ссылки в меню.

3. **`<script>…</script>`** внизу блока — вся логика:
   - анимации появления секций при скролле (`IntersectionObserver`);
   - параллакс hero-фото за курсором;
   - аккордеон FAQ (одна открытая карточка за раз);
   - **отправка формы заявки** — самое важное для настройки.

## Настройка формы заявки

В нижнем `<script>` в `index.html` есть блок настроек (ищи `НАСТРОЙКА:`):

- `TG_BOT_TOKEN` — токен Telegram-бота, которому приходят заявки.
- `TG_CHAT_ID` — ID чата/пользователя, куда бот шлёт заявку.
- `CRM_URL` — адрес Google Apps Script, который дублирует заявки в Google-таблицу.

При отправке формы заявка уходит одновременно в Telegram (основной канал) и в
Google Sheets (fire-and-forget, ошибки не показываются пользователю). После
успешной отправки показывается экран «Заявка ушла».

> ⚠️ Токен бота и chat_id лежат в открытом клиентском коде — так было в оригинале.
> Это позволяет любому отправлять сообщения этому боту. Если нужно закрыть —
> заявки лучше проксировать через серверный обработчик, а токен убрать из фронта.
